| Tujuan Pembelajaran (TP) | Kriteria Ketercapaian (Indikator) |
| :---- | :---- |
| **BAB 1: DUA KALIMAT SYAHADAT** |  |
| 1.1 Peserta didik dapat mengenal Dua Kalimat Syahadat. | Peserta didik mampu **menyebutkan** bahwa Dua Kalimat Syahadat adalah Rukun Islam yang pertama. |
| 1.2 Peserta didik dapat melafalkan Dua Kalimat Syahadat. | Peserta didik mampu **melafalkan** kalimat Syahadat Tauhid dan Syahadat Rasul dengan fasih dan benar. |
| **BAB 2: KALIMAT TAYIBAH** |  |
| 2.1 Peserta didik dapat melafalkan kalimat tayibah. | Peserta didik mampu **melafalkan** kalimat Basmalah, Hamdalah, dan Taawuz dengan benar. |
| 2.2 Peserta didik dapat mengidentifikasi waktu penggunaannya. | Peserta didik mampu **memberikan contoh** situasi yang tepat untuk mengucapkan Basmalah, Hamdalah, dan Taawuz. |
| **BAB 3: HIDUP SEHAT DAN BERSIH** |  |
| 3.1 Peserta didik dapat menerapkan cara menjaga kebersihan diri. | Peserta didik mampu **mendemonstrasikan** 6 langkah cuci tangan pakai sabun dengan benar. |
| 3.2 Peserta didik dapat melafalkan hadis tentang kebersihan. | Peserta didik mampu **melafalkan** hadis *"An-naẓāfatu minal-īmān"* beserta arti sederhananya. |
| **BAB 4: ADAB BELAJAR** |  |
| 4.1 Peserta didik dapat menyebutkan adab-adab belajar. | Peserta didik mampu **menyebutkan** minimal dua adab sebelum, dua adab saat, dan dua adab sesudah belajar. |
| 4.2 Peserta didik dapat menerapkan adab belajar. | Peserta didik **mempraktikkan** sikap memperhatikan guru dan berdoa sebelum dan sesudah belajar secara konsisten. |
| **BAB 5: KISAH KETELADANAN NABI MUHAMMAD SAW.** |  |
| 5.1 Peserta didik dapat menceritakan kembali kisah Nabi. | Peserta didik mampu **menceritakan kembali** salah satu kisah keteladanan Nabi dengan bahasa sendiri. |
| 5.2 Peserta didik dapat meneladani sifat Nabi. | Peserta didik mampu **memberikan contoh** perilaku jujur atau kasih sayang dalam kehidupan sehari-hari di sekolah. |
| **BAB 6: RUKUN IMAN** |  |
| 6.1 Peserta didik dapat menyebutkan enam Rukun Iman. | Peserta didik mampu **menyebutkan** keenam Rukun Iman secara lengkap dan berurutan. |
| 6.2 Peserta didik dapat menjelaskan arti sederhana Rukun Iman. | Peserta didik mampu **menjelaskan** arti dari minimal tiga Rukun Iman dengan bahasanya sendiri. |
| **BAB 7: SIFAT WAJIB ALLAH SWT.** |  |
| 7.1 Peserta didik dapat menjelaskan arti sifat Wujud, Qidam, Baqa'. | Peserta didik mampu **menjelaskan** arti sederhana dari sifat Wujud, Qidam, dan Baqa'. |
| 7.2 Peserta didik dapat menunjukkan bukti sifat Allah. | Peserta didik mampu **memberikan contoh** ciptaan Allah sebagai bukti sifat Wujud-Nya. |
| **BAB 8: ADAB MANDI DAN BERPAKAIAN** |  |
| 8.1 Peserta didik dapat menjelaskan tentang aurat. | Peserta didik mampu **menjelaskan** pengertian aurat secara sederhana dan menunjukkan batasannya pada gambar. |
| 8.2 Peserta didik dapat mempraktikkan adab berpakaian. | Peserta didik mampu **mendemonstrasikan** cara memakai pakaian atau sepatu dengan mendahulukan bagian kanan. |
| **BAB 9: JUJUR, TERIMA KASIH, DAN RENDAH HATI** |  |
| 9.1 Peserta didik dapat menjelaskan arti akhlak terpuji. | Peserta didik mampu **menjelaskan** arti dari jujur, terima kasih, dan rendah hati dengan kalimat sederhana. |
| 9.2 Peserta didik dapat menerapkan akhlak terpuji. | Peserta didik **mempraktikkan** ucapan terima kasih secara spontan dan menunjukkan sikap mau berbagi dengan teman. |

**Keterangan Tingkat Ketercapaian:**

* **Perlu Bimbingan:** Peserta didik belum mampu memenuhi kriteria dan memerlukan bimbingan pada hampir seluruh bagian.  
* **Cukup:** Peserta didik mampu memenuhi sebagian kriteria namun belum konsisten.  
* **Baik:** Peserta didik mampu memenuhi seluruh kriteria yang ditetapkan.  
* **Sangat Baik:** Peserta didik mampu memenuhi seluruh kriteria dengan analisis atau praktik yang lebih mendalam dan menunjukkan penguasaan konsep yang sangat baik.
