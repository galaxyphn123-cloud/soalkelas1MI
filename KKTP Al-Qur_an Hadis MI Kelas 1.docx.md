| **Bab 1: Mengenal Huruf Hijaiyah (1)** |  |
| 1.1. Melafalkan huruf-huruf hijaiyah ( ا \- خ ) dengan makhraj sederhana. | Peserta didik mampu **melafalkan** bunyi huruf hijaiyah dari Alif (ا) sampai Kha' (خ) sesuai contoh dari guru. |
| 1.2. Mengidentifikasi bentuk huruf hijaiyah ( ا \- خ ). | Peserta didik mampu **menunjuk** atau **menyebutkan** nama huruf hijaiyah dari Alif (ا) sampai Kha' (خ) yang ditunjukkan secara acak. |
| 1.3. Melafalkan huruf hijaiyah ( ا \- خ ) berharakat Fathah, Kasrah, Dammah. | Peserta didik mampu **melafalkan** bunyi huruf hijaiyah dari Alif (ا) sampai Kha' (خ) ketika diberi harakat dasar (a, i, u). |
| **Bab 2: Mengenal Surah al-Fatihah** |  |
| 2.1. Melafalkan ayat-ayat Surah Al-Fatihah. | Peserta didik mampu **menirukan** pelafalan ayat per ayat Surah Al-Fatihah dengan tartil sederhana. |
| 2.2. Menunjukkan hafalan Surah Al-Fatihah. | Peserta didik mampu **melafalkan** 7 ayat Surah Al-Fatihah secara urut dari hafalannya. |
| 2.3. Menjelaskan informasi dasar tentang Surah Al-Fatihah. | Peserta didik mampu **menyebutkan** bahwa Al-Fatihah adalah surah pertama, artinya "Pembukaan", dan berjumlah 7 ayat. |
| **Bab 3: Mengenal Surah An-Nas** |  |
| 3.1. Melafalkan ayat-ayat Surah An-Nas. | Peserta didik mampu **menirukan** pelafalan ayat per ayat Surah An-Nas dengan tartil sederhana. |
| 3.2. Menunjukkan hafalan Surah An-Nas. | Peserta didik mampu **melafalkan** 6 ayat Surah An-Nas secara urut dari hafalannya. |
| 3.3. Menjelaskan fungsi Surah An-Nas sebagai doa perlindungan. | Peserta didik mampu **menjelaskan** dengan kalimat sederhana bahwa Surah An-Nas dibaca untuk memohon perlindungan Allah. |
| **Bab 4: Mengenal Surah Al-Falaq** |  |
| 4.1. Melafalkan ayat-ayat Surah Al-Falaq. | Peserta didik mampu **menirukan** pelafalan ayat per ayat Surah Al-Falaq dengan tartil sederhana. |
| 4.2. Menunjukkan hafalan Surah Al-Falaq. | Peserta didik mampu **melafalkan** 5 ayat Surah Al-Falaq secara urut dari hafalannya. |
| 4.3. Menjelaskan fungsi Surah Al-Falaq & mengenal istilah *mu'awwidzatain*. | Peserta didik mampu **menyebutkan** bahwa Al-Falaq dan An-Nas adalah surah perlindungan (*mu'awwidzatain*). |
| **Bab 5: Mengenal Surah Al-Ikhlas** |  |
| 5.1. Melafalkan ayat-ayat Surah Al-Ikhlas. | Peserta didik mampu **menirukan** pelafalan ayat per ayat Surah Al-Ikhlas dengan tartil sederhana. |
| 5.2. Menunjukkan hafalan Surah Al-Ikhlas. | Peserta didik mampu **melafalkan** 4 ayat Surah Al-Ikhlas secara urut dari hafalannya. |
| 5.3. Menjelaskan makna "Allahu Ahad" & "Allahu Ash-Shamad". | Peserta didik mampu **menjelaskan** bahwa "Allahu Ahad" artinya Allah Maha Esa dan "Allahu Ash-Shamad" artinya Allah tempat meminta. |
| **Bab 6: Mengenal Surah Al-Lahab** |  |
| 6.1. Melafalkan ayat-ayat Surah Al-Lahab. | Peserta didik mampu **menirukan** pelafalan ayat per ayat Surah Al-Lahab dengan tartil sederhana. |
| 6.2. Menunjukkan hafalan Surah Al-Lahab. | Peserta didik mampu **melafalkan** 5 ayat Surah Al-Lahab secara urut dari hafalannya. |
| 6.3. Menceritakan sebab turunnya surah & mengambil ibrahnya. | Peserta didik mampu **menyebutkan** bahwa perbuatan Abu Lahab (menyakiti Nabi) adalah perbuatan yang tidak boleh ditiru. |
| **Bab 7: Mengenal Huruf Hijaiyah (2)** |  |
| 7.1. Melafalkan huruf hijaiyah berharakat Tanwin. | Peserta didik mampu **membedakan** dan **melafalkan** bunyi huruf dengan harakat Fathatain, Kasratain, dan Dhammatain. |
| 7.2. Melafalkan gabungan huruf yang mengandung Sukun. | Peserta didik mampu **melafalkan** bunyi konsonan mati pada gabungan dua huruf (contoh: *ab, um, is*). |
| 7.3. Melafalkan huruf hijaiyah berharakat Tasydid. | Peserta didik mampu **melafalkan** bunyi huruf ganda dengan penekanan yang benar (contoh: *rab-ba, sum-ma*). |
| **Bab 8: Mengenal Surah An-Nashr** |  |
| 8.2. Menunjukkan hafalan Surah An-Nashr. | Peserta didik mampu **melafalkan** 3 ayat Surah An-Nashr secara urut dari hafalannya. |
| 8.3. Menjelaskan tiga perintah Allah dalam surah. | Peserta didik mampu **menyebutkan** perintah untuk memuji Allah (bertasbih dan bertahmid) dan meminta ampun (beristighfar). |
| **Bab 9: Mengenal Surah Al-Kafirun** |  |
| 9.2. Menunjukkan hafalan Surah Al-Kafirun. | Peserta didik mampu **melafalkan** 6 ayat Surah Al-Kafirun secara urut dari hafalannya. |
| 9.3. Menjelaskan makna "Lakum diinukum waliya diin". | Peserta didik mampu **menjelaskan** dengan kalimat sederhana bahwa kita harus menghargai teman yang berbeda agama. |
| **Bab 10: Mengenal Surah Al-Kautsar** |  |
| 10.2. Menunjukkan hafalan Surah Al-Kautsar. | Peserta didik mampu **melafalkan** 3 ayat Surah Al-Kautsar secara urut dari hafalannya. |
| 10.3. Menyebutkan dua perintah Allah sebagai wujud syukur. | Peserta didik mampu **menyebutkan** perintah untuk salat dan berkurban sebagai cara bersyukur. |
| **Bab 11: Mengenal Surah Al-Ma'un** |  |
| 11.2. Menunjukkan hafalan Surah Al-Ma'un. | Peserta didik mampu **melafalkan** 7 ayat Surah Al-Ma'un secara urut dari hafalannya. |
| 11.3. Menyebutkan ciri-ciri pendusta agama. | Peserta didik mampu **menyebutkan** minimal dua contoh ciri pendusta agama (misal: tidak sayang anak yatim, tidak mau menolong). |
| **Bab 12: Mengenal Surah Quraisy** |  |
| 12.2. Menunjukkan hafalan Surah Quraisy. | Peserta didik mampu **melafalkan** 4 ayat Surah Quraisy secara urut dari hafalannya. |
| 12.3. Menyebutkan dua nikmat utama dalam surah. | Peserta didik mampu **menyebutkan** nikmat makanan (dihilangkan dari lapar) dan nikmat rasa aman (dihilangkan dari takut). |
| **Bab 13: Aku Cinta Kebersihan** |  |
| 13.1. Melafalkan hadis tentang kebersihan. | Peserta didik mampu **melafalkan** hadis "Ath-thuhuuru syathrul-iimaan" dengan fasih. |
| 13.2. Menunjukkan hafalan hadis tentang kebersihan. | Peserta didik mampu **melafalkan** hadis tentang kebersihan dari hafalannya. |
| 13.3. Menjelaskan arti "kebersihan sebagian dari iman". | Peserta didik mampu **menjelaskan** bahwa orang yang beriman harus suka menjaga kebersihan. |

**Keterangan Tingkat Ketercapaian:**

* **Perlu Bimbingan:** Peserta didik belum mampu memenuhi kriteria dan memerlukan bimbingan pada hampir seluruh bagian.  
* **Cukup:** Peserta didik mampu memenuhi sebagian kriteria namun belum konsisten.  
* **Baik:** Peserta didik mampu memenuhi seluruh kriteria yang ditetapkan.  
* **Sangat Baik:** Peserta didik mampu memenuhi seluruh kriteria dengan sangat baik, lancar, dan menunjukkan pemahaman yang mendalam.
